# Atlassian Jira Lab

## Project Overview
This portfolio documents my hands-on experience learning and using Atlassian Jira for IT work management and ticket tracking.

## Skills Demonstrated
- Work item creation and management
- Kanban boards
- Status and priority management
- Ticket assignment
- Jira Query Language (JQL)
- Saved filters
- Quick filters
- Workflows
- Custom fields
- Automation
- Dashboards and reporting

## Jira Query Language (JQL) & Filters

### My Active Work
Created a JQL filter to display active work assigned to the current user.

### High Priority Active Work
Created a filter to identify high-priority work that still requires attention.

### Quick Filters
Created board-level quick filters for:
- My Work
- High Priority
- Unassigned Work

## Kanban Board & Ticket Management
Created and managed Jira work items by assigning users, setting priorities, updating statuses, documenting work, and resolving tickets.
